# Stahl's Link Cable Item (Gen 1 & Gen2)
This is a mod for gen1recomp that adds a new item (the LINK CABLE). It works like an evolution stone, meaning you can evolve HAUNTER, GRAVELER, MACHOKE, KADABRA, and for the Gen2 version, POLIWHIRL, SLOWPOKE, ONIX, SCYTHER, SEADRA, and PORYGON.

To integrate the new item more naturally with the game, the LINK CABLE can be bought at the CELADON mart (as well as GOLDENROD mart in Gen2) where you can buy the evolution stones, for the same price (P$ 2100) as those. You can also find two of them in the overworld, one of them as a visible item on the ground and another one as a hidden one. 

In Gen1, two NPCs in the Route 16 gate house's top floor also had their dialogue lines changed to talk about trading and mention the LINK CABLE.

> [!IMPORTANT]
> This mod ONLY works in Gen1 and Gen2 games!
> 
> You need to download and install the version of the mod for the gen(s) that you want to use it for. If you want to use it in Gen1 AND in Gen2, download and install both versions!
>
> They are perfectly compatible with each other as long as you don't try to force them to be enabled in the respective other gen they weren't made for!

## How to Use
- Download the zipped mod(s) from the Releases page and install it via the mod manager of the recomp launcher as normal.
- Install ST_LinkCableItem_GEN1 for Gen1 games, and ST_TradeEvoItems_GEN2 for Gen2 games.
- Make sure the mod is enabled.
- **Gen1:** Buy a LINK CABLE from the CELADON mart or find one in the overworld.
- **Gen2:** Buy a LINK CABLE from the GOLDENROD mart, or find/buy a KING ROCK (for POLITOED and SLOWKING), METAL COAT (for STEELIX and SCIZOR), a DRAGON SCALE (KINGDRA), or an UPGRADE (PORYGON 2).
- Use the evolution item on a Pokemon in your team that can evolve via trade, like you would use an evolution stone.
- Your Pokemon will evolve and the item is consumed.

> [!CAUTION]
> This is NOT A ROMHACK, it only works with [Gen1Recomp](https://github.com/bryanthaboi/gen1recomp)!
